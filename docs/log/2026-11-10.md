# 2026-11-10 — Linux/NixOS port

Session goal (owner, via the Nexus iOS session): an identical Nexus Desktop for
Linux, run from the owner's NixOS machine, in a new private repo
`ljcatherine/NexusNix`, with a Nix flake and an honest parity checklist.

## Inventory

- Cloned NexusWindows read-only at `2e83c4d` (0.1.13). 16 crates, ~17k lines of
  Rust. Most of it (egui/eframe, portable-pty, alacritty_terminal, russh, rusqlite,
  keyring, rfd) is already cross-platform.
- Windows-only: DWM title bar, DPAPI session store, HKCU URL scheme, Credential
  Manager wording, `%APPDATA%`/`%LOCALAPPDATA%`/`%USERPROFILE%`/`%COMPUTERNAME%`,
  `rundll32`/`cmd /C start`/`explorer /select`, `CREATE_NO_WINDOW`, `.cmd` shims,
  Windows OpenSSH paths, ConPTY shells (PowerShell, cmd, WSL, Git Bash), Segoe
  fonts and Fluent icon code points, `winresource`, WiX MSI, `release.ps1`,
  Codex Windows sandbox. Mapping and decisions: `docs/PARITY-LINUX.md`.

## Decisions

- Rust: nixpkgs `nixos-26.05` ships 1.95; the code builds on it, so the workspace
  `rust-version` is 1.95 here (Windows: 1.99).
- `rfd` uses the XDG portal backend (no GTK build dependency).
- Access session: AES-256-GCM file with the key in the Secret Service rather
  than the whole token in the keystore, keeping the file-based API and tests.
- XWayland by default, `NEXUS_WAYLAND=1` for native Wayland (minimise lock).
- Package is `unfree` (proprietary licence); the flake allows exactly
  `nexus-desktop` for its own outputs.
- SSH test keys are generated per run with `ssh-keygen`; none are committed.

## Verification (this machine: NixOS 26.05, KDE Plasma 6 Wayland, KWallet)

- `cargo test --workspace`: 121 passed, 0 failed, 1 ignored. PTY test spawned
  `sh` and saw exit code 3. `cargo test -p nexus-access -- --ignored`: Secret
  Service round trip passed against KWallet.
- `nix build`: built `nexus-desktop`, `NexusDesktop`, `nexus-ro`, desktop entry;
  cargoCheckHook ran the workspace tests: 121 passed, 1 ignored.
- Launch: `NEXUS_SCREENSHOT` self-capture of the dashboard and of the IDE with a
  file, the minimap and a bash terminal; Codex was found in `~/.npm-global/bin`
  and showed "Connected". Directories created 0700.
- App lock: with `app_lock` on and a throwaway secret, the app opened locked.
  xdotool (XTEST) and ydotool (uinput) keystrokes did not reach the window, so
  unlocking was not exercised; the throwaway secret and the test session key
  were removed from KWallet afterwards.
- Minimise: a probe with the same eframe features, minimised by KWin under
  XWayland (`WM_STATE` Iconic), reported `minimized == Some(true)` in
  `App::logic` but `ui` was never called while minimised; under native Wayland
  it reported `Some(false)`. Hence the `App::logic` check in `app.rs`.
