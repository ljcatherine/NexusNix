# 2026-11-11 — one passcode key for several PCs

- Request (owner): one code that works for both NexusNix and NexusWindows; the
  iPhone app can only be paired with one PC because each desktop's
  *Set up with iPhone* generates a new key.
- Design: keep one key and share it between desktops, so the iPhone needs no
  change. A paired, unlocked desktop shows its key only after a current code
  (`AppLock::try_reveal`, counted by the same attempt limiter); another desktop
  joins with that key plus a current code (`verify_existing_key`, 10 bytes,
  canonical base32, lock enabled only after the code verifies).
- `docs/OTP.md` gained "More than one PC" and Linux wording; copied
  byte-identically to NexusWindows and the iOS repo.
- Tests: `existing_key_from_another_pc_is_normalised_and_verified`,
  `reveal_needs_a_current_code_and_counts_failures`; workspace 123 passed,
  1 ignored. Settings screenshot shows *Set up with iPhone…* and *Use the key
  from another PC…*. No real two-PC/phone run.
